# LumiLink（デモ版）

学生と教員の日常的なコミュニケーションを支援し、AIによる要約・タスク生成・成長可視化を行う教育現場向けプラットフォーム「LumiLink」のデモアプリです。

## 特徴

- 白背景・アニメーション付きの表紙画面（タイトルが左から右へ流れて出現）
- 学生 / 教員のロール選択から始まるオンボーディング
- 学生・教員間の1対1チャット（音声・ビデオ通話はデモ用のログ表示）
- AIによる会話要約（疑似AIロジック。会話内容からトピック・ムード・要点を自動生成）
- AIによるタスク自動提案 + 教員による手動タスク割り当て
- 半年間の成長データの可視化（積極性・対話量・タスク遂行・心理的安定度）とAIによる成長分析コメント
- 教員によるメモ・評価の記録（関心・不安・評価タグ付き）
- 状態はブラウザの localStorage に保存され、リロードしても保持されます

## AI機能について

このデモではAPIキーを使わず、`src/services/aiService.ts` 内でキーワード解析による疑似AIロジックを実装しています。
本物のLLM API（OpenAIなど）に差し替える場合も、この関数群のシグネチャ（引数・返り値の型）を変えずに内部実装をAPI呼び出しに置き換えるだけで対応できるように設計しています。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:5173` を開いてください。

## ビルド

```bash
npm run build
```

## 技術スタック

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion（アニメーション）
- Recharts（成長グラフ）
- lucide-react（アイコン）

## デモの使い方

1. 表紙画面で「はじめる」をクリック
2. 「学生として利用」または「教員として利用」を選び、サンプルアカウントを選択
3. 学生: チャットで教員とやり取り → 「会話をAIで要約する」「次のタスクを提案してもらう」を試す → タスク画面・成長記録画面を確認
4. 教員: 学生管理から学生を選択 → チャット・メモ・タスク管理・成長記録の各タブを確認
